# ⚽🧤 BALL VS KEEPER — الكرة ضد الحارس

لعبة ثلاثية الأبعاد بنظام **كونسل** على شبكتك المحلية (نفس الواي فاي). لا تحتاج إنترنت، ولا Firebase، ولا أي خدمة خارجية.
الشاشة الكبيرة (كمبيوتر / لابتوب / تلفزيون / تابلت) تعرض اللعبة، والتلفونات تتحول إلى أيدي تحكم.

---

## 🚀 التشغيل السريع

```bash
npm install        # مرة واحدة: تثبيت المكتبات (three, ws, qrcode ...)
npm run build      # بناء اللعبة إلى مجلد dist (ملف index.html واحد فيه Three.js وكل الكود)
node server.js     # تشغيل السيرفر المحلي
```

ستطبع الطرفية شيئاً مثل:

```
🖥️  افتح اللعبة على الشاشة الكبيرة:  http://192.168.1.20:3000
📱  رابط اليد للتلفون:              http://192.168.1.20:3000/pad
```

1. افتح الرابط الأول على الشاشة الكبيرة (أي متصفح حديث: Chrome / Edge / Firefox / متصفح التلفزيون).
2. اضغط **لعب** لتدخل غرفة الانتظار؛ سيظهر **QR Code** ورابط و**رمز غرفة من 4 أرقام**.
3. امسح الـ QR بكاميرا التلفون (أو افتح `/pad` وأدخل الرمز)، واختر دورك (كرة أو حارس).
4. اضغط **ابدأ المباراة**.

> تغيير المنفذ: `PORT=8080 node server.js`
> إذا لم يفتح التلفون الرابط: تأكد أن الجهازين على نفس الواي فاي، واسمح لـ Node.js في جدار الحماية (Windows Firewall) على الشبكات الخاصة.

## 🎮 التحكم

| الجهاز | الحركة | تسديد (اضغط مطولاً) | قفز | غطس |
|---|---|---|---|---|
| ⌨️ كيبورد اللاعب 1 | W A S D | Space | Space | E |
| ⌨️ كيبورد اللاعب 2 | الأسهم | Enter | Enter | Shift |
| 🎮 يد بلايستيشن / إكسبوكس | العصا اليسرى / الأسهم | ✕ / A | ○ / B | □ / X |
| 📱 التلفون | العصا الافتراضية | زر تسديد | زر قفز | زر غطس |

- **الإيقاف المؤقت:** Esc أو P أو زر Start أو زر ⏸️ في التلفون.
- **التسديد:** اضغط زر التسديد مطولاً ← يتعبّى شريط القوة وتظهر علامة تصويب على المرمى تحركها بالعصا ← أفلت للتسديد.
  أمِل العصا يميناً/يساراً **لحظة الإفلات** لتنحني الكرة (Curve). القوة القصوى أقل دقة!
- **الحارس:** يمين/يسار للحركة، قفز للكرات العالية، غطس باتجاه العصا (ادفع العصا للأعلى مع الاتجاه = غطس عالٍ). للغطس كولداون ثانيتين يظهر في شريط أسفل الشاشة.
- أي لاعب يقدر يستخدم أي جهاز، ويمكن الخلط (مثلاً: لاعب بالتلفون وآخر بيد إكسبوكس).
- يد التحكم: اضغط أي زر للانضمام، ويمين/يسار في غرفة الانتظار لتبديل اللاعب.

## 🏆 القواعد
- كل جولة 30 ثانية (قابلة للتعديل)، وبعدها تتبدل الأدوار. 6 جولات افتراضياً.
- هدف = نقطة. التعادل في النهاية ← **هدف ذهبي**: الأدوار تتبدل بعد كل محاولة وأول هدف يفوز.

## 🧱 بنية المشروع

```

public/pad.html      صفحة يد التحكم للتلفون (HTML/JS خالص، لمس متعدد، إعادة اتصال، اهتزاز)
index.html           صفحة اللعبة (تُبنى إلى dist/index.html كملف واحد)
src/game/
  settings.ts        الإعدادات + localStorage
  i18n.ts            النصوص عربي/إنجليزي
  physics.ts         Physics: الكرة، الجاذبية، الارتداد، الانحناء، القائمين، الشبكة، الحارس
  engine.ts          Game + Camera/FX: الحالة والجولات، الكاميرا، الإعادة، الجزيئات، الحركة البطيئة
  scene.ts           بناء الملعب والمدرجات والحارس والكرة (أشكال بسيطة خفيفة)
  input.ts           Input: كيبورد + Gamepad API + التلفون
  network.ts         Network: اتصال الكونسل بالسيرفر والغرف وإعادة الاتصال
  audio.ts           Audio: أصوات مولدة بـ Web Audio API (جمهور، تسديد، صد، هدف، صافرة، موسيقى)
  ai.ts              الذكاء الاصطناعي (مهاجم وحارس)
src/ui/              UI: القائمة، التعليمات، الإعدادات، غرفة الانتظار، واجهة اللعب
```

## 🪜 مراحل البناء وكيف تجرب كل مرحلة

### المرحلة 1 — الملعب والفيزياء والجولات (كيبورد على نفس الجهاز)
- شغّل `npm run build && node server.js` وافتح `http://localhost:3000` (أو `npm run dev` للتطوير).
- لعب ← ابدأ المباراة. اللاعب 1 بـ WASD + Space، واللاعب 2 بالأسهم + Enter + Shift.
- جرّب: التسديد بالقوة، الانحناء، ارتداد الكرة من القائم والعارضة، صد الحارس، العد التنازلي، تبديل الأدوار، شاشة النهاية، وتبديل اللغة (RTL).

### المرحلة 2 — يد البلايستيشن/الإكسبوكس + الصوت والمؤثرات والكاميرا
- وصّل اليد بالكمبيوتر (USB أو بلوتوث) واضغط أي زر في غرفة الانتظار ← تظهر تحت اللاعب.
- لاحظ: صوت الجمهور، صافرة البداية، صوت التسديد/الصد/الهدف، كاميرا تقترب لحظة التسديد، حركة بطيئة عند التسديد القوي، إعادة الهدف من خلف الشبكة (تخطيها بأي زر)، جزيئات الاحتفال، اهتزاز الكاميرا عند الصد، واهتزاز اليد.

### المرحلة 3 — التلفون كيد تحكم عبر الشبكة
- شغّل `node server.js` وافتح الرابط المطبوع (عنوان IP وليس localhost) على الشاشة الكبيرة.
- امسح الـ QR من التلفون ← تظهر يد التحكم. جرّب اللمس المتعدد (العصا + زر معاً) والاهتزاز عند التسديد والهدف.
- أطفئ الواي فاي في التلفون أثناء اللعب ← تتوقف اللعبة ويظهر تنبيه، وعند الرجوع تكمل بعد عد 3-2-1 تلقائياً.
- أعد تحميل صفحة اللعبة ← تبقى الغرفة بنفس الرمز ويرجع التلفون تلقائياً.

### المرحلة 4 — وضع الكمبيوتر وتحسين الأداء
- في غرفة الانتظار اختر **ضد الكمبيوتر**، وحدد الصعوبة من الإعدادات (سهل/عادي/صعب).
- الإعدادات ← الجودة (منخفض/متوسط/عالٍ) + خفض الجودة تلقائياً إذا نزل الأداء تحت ~42 إطاراً بالثانية. عدّاد الإطارات أعلى الشاشة.
