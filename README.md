# ⚽🧤 BALL VS KEEPER — الكرة ضد الحارس

لعبة كرة قدم ثلاثية الأبعاد بنظام شاشة كبيرة + هواتف كأيدي تحكم. تدعم اللعب محليًا أو عبر الإنترنت من خلال استضافة المشروع على **Render**. لا تستخدم Firebase ولا تحتاج إلى خدمة قاعدة بيانات خارجية؛ غرف اللعب والاتصال اللحظي تُدار بواسطة WebSocket داخل سيرفر اللعبة.

## 🌍 النشر على Render

1. ارفع ملفات هذا المشروع إلى مستودع GitHub خاص أو عام.
2. افتح [Render](https://render.com) وسجّل الدخول.
3. اختر **New + → Web Service** ثم اربط مستودع GitHub.
4. استخدم الإعدادات التالية:
   - **Runtime:** Node
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/api/health`
5. اضغط **Create Web Service** وانتظر انتهاء البناء.
6. افتح رابط Render الذي ينتهي بـ `onrender.com` على الكمبيوتر/التلفزيون.
7. ادخل غرفة الانتظار؛ سيظهر رمز الغرفة. افتح الرابط نفسه على الهاتف مع `/pad` في النهاية، مثل `https://your-service.onrender.com/pad`، ثم أدخل الرمز أو امسح QR إن ظهر.
8. يجب أن يكون رابط اللعبة ورابط الهاتف على نفس خدمة Render. الاتصال يستخدم `wss://` تلقائيًا عند العمل عبر HTTPS.

> **مهم:** Render يجعل اللعبة متاحة عبر الإنترنت، لكن الخدمة المجانية قد تدخل وضع السكون بعد عدم النشاط؛ أول فتح بعد السكون قد يحتاج وقتًا حتى تستيقظ. لا تضع أسرارًا أو مفاتيح خاصة داخل كود الواجهة.

## 🖥️ تشغيل محليًا (اختياري)

```bash
npm install
npm run build
npm start
```

افتح الرابط الذي يطبعه السيرفر على الكمبيوتر، ثم افتح `/pad` على الهاتف. للاستخدام المحلي يجب أن يكون الجهازان على نفس الشبكة.

## 🎮 التحكم

| الجهاز | الحركة | تسديد | قفز | غطس |
|---|---|---|---|---|
| كيبورد اللاعب 1 | W A S D | Space (اضغط مطولًا) | Space | E |
| كيبورد اللاعب 2 | الأسهم | Enter (اضغط مطولًا) | Enter | Shift |
| يد ألعاب | العصا اليسرى / الأسهم | ✕ / A | ○ / B | □ / X |
| الهاتف | عصا لمس افتراضية محسّنة | زر التسديد | زر القفز | زر الغطس |

العصا الافتراضية فيها حلقة اتجاهات ومقبض مضيء، وتظهر عند لمس منطقة الحركة في موضع الإصبع. يمكن تحريك العصا والضغط على الأزرار في الوقت نفسه. يُفضّل تدوير الهاتف إلى الوضع الأفقي والضغط على زر ملء الشاشة لتجربة أفضل.

## 🧱 ملاحظات تقنية

- `server.js`: تقديم ملفات اللعبة وإدارة الغرف واتصالات WebSocket.
- `public/pad.html`: واجهة يد التحكم للهاتف.
- `src/game/network.ts`: اتصال شاشة اللعبة بالسيرفر.
- Render يستخدم HTTPS/WSS تلقائيًا، ولا يلزم تغيير عنوان IP أو فتح منافذ على الراوتر.
- غرف اللعب محفوظة في ذاكرة السيرفر؛ إذا أعاد Render تشغيل الخدمة أو نامت، قد تنتهي الغرف الحالية ويحتاج اللاعبون إلى إنشاء غرفة جديدة.
